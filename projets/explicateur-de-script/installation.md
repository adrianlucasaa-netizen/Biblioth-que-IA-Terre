## Étapes communes

1. Ouvrez une nouvelle conversation dans votre outil d'IA.
2. Copiez tout le contenu de `prompt.md` et envoyez-le comme premier message.
3. Dans un second message, collez le code du script.
4. Pour tester : collez `exemples/script-fictif.py` et comparez avec `exemples/explication-attendue.md`.

Les réponses varient d'une IA à l'autre et d'une fois à l'autre.
