## Étapes communes

1. Vérifiez que Python 3 est installé : tapez `python --version` dans un terminal (sous Linux ou macOS, parfois `python3`).
2. Copiez le fichier `nettoyer_csv.py` dans le dossier de votre choix.
3. Pour tester, lancez : `python nettoyer_csv.py exemples/entree-fictive.csv`. Le fichier `entree-fictive_propre.csv` apparaît à côté.
4. Comparez-le à `exemples/sortie-attendue.csv`.
5. Pour vos fichiers, utilisez uniquement des copies de travail ne contenant aucune donnée sensible.

Le script ne nécessite aucune installation de bibliothèque : il n'utilise que Python.
