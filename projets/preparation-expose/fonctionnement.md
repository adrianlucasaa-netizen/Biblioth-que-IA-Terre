# Fonctionnement

## Cadrage
- qui: vous
- entrée: Le sujet, le public, la durée et vos idées en vrac.
- sortie: Un message principal en une phrase.

Vous écrivez votre demande sans la structurer. Le message à retenir est la seule chose à bien définir : tout le reste en découle.

```exemple
Message : un retour d'expérience court et régulier vaut mieux qu'un bilan long.
```

## Proposition de plan
- qui: ia
- entrée: Votre demande et, si fourni, le fichier de consignes.
- sortie: Un plan en trois ou quatre parties avec les durées.

L'IA reformule d'abord la demande, puis propose le plan. Elle s'arrête et attend votre réponse.

```exemple
1. Pourquoi (5 min)
2. La méthode (7 min)
3. Un exemple (5 min)
4. Les pièges (3 min)
```

## Validation du plan
- qui: vous
- entrée: Le plan proposé.
- sortie: Un plan accepté, corrigé ou refusé.

C'est le garde-fou central du projet : sans votre accord, rien ne suit. Changez l'ordre, supprimez une partie, ajustez les durées.

```exemple
Je supprime la partie 4 et j'ajoute 3 minutes à la partie 2.
```

## Diapositives et notes
- qui: ia
- entrée: Le plan validé.
- sortie: Les diapositives (trois puces au plus) et les notes de l'orateur, avec les questions probables.

Toute affirmation sans source fournie est marquée `[SOURCE À AJOUTER]`.

```exemple
Affirmation à sourcer : [SOURCE À AJOUTER]
```

## Répétition
- qui: vous
- entrée: Les diapositives et les notes.
- sortie: Un exposé chronométré à voix haute.

Vous vous chronométrez, vous retirez ce qui dépasse, vous vérifiez chaque source face à l'original.

```exemple
Durée mesurée : 22 minutes, je coupe un exemple.
```
