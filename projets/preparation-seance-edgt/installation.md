## Étapes communes

Ce projet est écrit pour Claude, et pour Claude seulement. Il demande un compte Claude avec les projets et la création de fichiers. Dans la fiche de ce projet, l'onglet des fichiers affiche chaque fichier avec un bouton « Copier le contenu » : il n'y a rien à télécharger ni à décompresser.

## Claude

1. **Activer la création de fichiers.** Dans Claude, ouvrez « Settings », puis « Capabilities », et activez « Code execution and file creation ». C'est ce qui permet à Claude de créer un fichier PowerPoint. D'après l'aide officielle, cette option est disponible sur les formules Free, Pro, Max, Team et Enterprise. Sur Team et Enterprise, elle dépend de l'organisation.
2. **Créer le projet.** Ouvrez « Projects », puis « New Project », et nommez-le « Préparation de séance ».
3. **Coller les instructions.** Dans le projet, cliquez sur « Set project instructions ». Dans la fiche de la bibliothèque, ouvrez `instructions.md`, cliquez sur « Copier le contenu », collez dans Claude et enregistrez.
4. **Adapter les réglages.** En haut du texte collé, la section « Réglages » donne la durée, le débit de parole, le public, la charte et les layouts. Changez ce qui ne correspond pas à votre cas. Vous pouvez y revenir plus tard.
5. **Lancer une préparation.** Ouvrez une conversation dans le projet. Décrivez votre sujet, comme dans `exemples/demande-exemple.md`. Pour utiliser votre propre gabarit PowerPoint, joignez-le à ce premier message.
6. **Suivre les étapes.** Claude vous demande de confirmer le sujet, construit le fond avec vous, vous présente le plan et les illustrations (comparez avec `exemples/fond-valide-exemple.md`), puis crée le fichier. Il ne le crée pas avant votre accord.

Les banques d'images et les outils de schémas (connecteurs Claude) sont facultatifs. Sans eux, Claude propose des schémas qu'il dessine lui-même, ou vous demande de fournir l'image.

Les noms des menus changent selon les versions de Claude. En cas de doute, consultez l'aide officielle : [créer et gérer des projets](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects) et [créer et modifier des fichiers avec Claude](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude).
