## Étapes communes

1. Récupérez le dossier de ce projet ; le fichier essentiel est `SKILL.md`.
2. Si votre outil sait charger un skill, installez-le (voir ci-dessous). Sinon, copiez le contenu de `SKILL.md`, sans l'en-tête entre les deux lignes `---`, au début d'une conversation.
3. Testez : collez `exemples/articles-fictifs.md` et comparez avec `exemples/veille-attendue.md`.

Les noms des menus et le format des skills changent selon les versions des outils. Vérifiez dans l'aide de votre outil.

## Claude

Ce skill est écrit au format de Claude (un fichier `SKILL.md` avec un en-tête `name` et `description`). Ajoutez-le dans les capacités ou les skills de votre compte si l'option existe dans votre version, ou utilisez son contenu comme prompt dans une conversation.
